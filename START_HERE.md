# START HERE — Risksir agent pack

This pack turns an empty GitHub repo into a Claude Code workspace that runs itself. Claude writes the engineering contract, builds the product milestone by milestone, runs tests, and commits and pushes to GitHub after every verified milestone.

## What is in the pack

| File | Written by | Role |
| --- | --- | --- |
| `CLAUDE.md` | you (pre-written) | Permanent operating rules for Claude: autonomy, priorities, stop conditions, git |
| `OPERATIONAL_GUARDRAILS.md` | you (pre-written) | Hard limits: secrets, networks, spend caps, API quota, forbidden git ops |
| `docs/` | you | Frozen inputs: `00_HACKATHON_CONTEXT`, `07_PROJECT_FREEZE`, `08_SYSTEM_DEPENDENCY_DESIGN`, `PRIZE_ANCHOR_INTERCEPTA` |
| `prompts/00_BOOTSTRAP.md` | you | The master prompt. It writes `REPO_AUDIT`, `SPEC`, `DECISIONS`, `TEST_PLAN`, `EXECUTION_PLAN` and `HANDOFF`, pushes them, then starts building |
| `prompts/NEXT.md` | you | The daily loop: next milestone, implement, test, commit, push, handoff |
| `prompts/WRAP` `FIX` `UI_FEEDBACK` `DEMO_AND_SUBMISSION` | you | End-of-session, bug, UX and submission prompts |
| `.claude/commands/rs-*.md` | you | Slash commands: `/rs-bootstrap` `/rs-next` `/rs-wrap` `/rs-fix` `/rs-ui` `/rs-demo` |
| `.claude/settings.json` | you | Permissions. Normal dev commands are auto-allowed. Force push, `.env` reads, `rm -rf`, `sudo` and repo create/delete are denied |
| `.githooks/pre-commit` + `scripts/guard-secrets.sh` | you | Blocks any commit that contains an `.env` file or the value of a secret |
| `scripts/env-status.sh` | you | Shows which env vars are SET or MISSING without printing values |
| `scripts/agent-loop.sh` | you | Headless auto mode: runs fresh Claude sessions back to back until it needs you |
| `SPEC.md`, `EXECUTION_PLAN.md`, … | **Claude** | Generated by the bootstrap. `AGENTS.md` is generated in M-000 |

## Setup (about 10 minutes, once)

```bash
# 1. Create an empty GitHub repo named "risksir" (private for now; go public before submission), then:
git clone git@github.com:<you>/risksir.git && cd risksir

# 2. Copy this pack into the repo root (including the hidden .claude/, .githooks/, .env.example, .gitignore)

# 3. Tooling
corepack enable            # gives you pnpm; Node 20+ required (22 LTS recommended)
git config core.hooksPath .githooks
chmod +x .githooks/pre-commit scripts/*.sh

# 4. Secrets: fill in what you have now; the agent works around what's missing
cp .env.example .env       # then edit .env
bash scripts/env-status.sh
```

Fill these in `.env` as early as possible. The live milestones wait on them:

- **`INTERCEPTA_API_KEY`**: the sponsor sandbox key. Also set `INTERCEPTA_BASE_URL`.
- **`PAYER_PRIVATE_KEY`**: a **fresh** wallet. Fund it with Base Sepolia ETH and a few test USDC from a faucet.
- **`SELLER_PAY_TO_SAFE`**: any normal address you control.
- **`SELLER_PAY_TO_RISKY`**: the sponsor's known-risk **mainnet** address (ask on Discord or at the booth). Also confirm with them that you may use it as a testnet merchant `payTo`.
- **`OWNER_CONSOLE_TOKEN`**: any long random string.

## Run it

**Option A — interactive.** Recommended for the first run, so you can watch it.

```bash
claude
> /rs-bootstrap
```

It writes the contract, commits, pushes and then keeps building. Whenever it stops, read the top of `HANDOFF.md`, do the `HUMAN_ACTIONS`, then type `/rs-next`.

**Option B — fully automatic.** You can walk away.

```bash
./scripts/agent-loop.sh              # 6 fresh sessions max
MAX_ITER=12 ./scripts/agent-loop.sh  # longer run
touch .agent/STOP                    # ask it to stop after the current session
```

It stops by itself on `HUMAN_REQUIRED`, `ALL_DONE`, or two sessions in a row without a commit.

## Daily commands

| You want to… | Type |
| --- | --- |
| Continue building | `/rs-next` |
| Continue with a nudge | `/rs-next prioritise M-005 before the console` |
| Fix a bug | `/rs-fix Observed: v2 still returns PAY for first-time 0.05. Expected: ASK_HUMAN` |
| Change the UX | `/rs-ui Current: judges can't see the signer count. Desired: big "signer calls: 0" badge on the trace` |
| End the day cleanly | `/rs-wrap` |
| Prepare the demo and submission | `/rs-demo` |

## Things only you can do

1. Get the Intercepta key and the known-risk address, and fund the payer wallet.
2. **Spike E:** ask Intercepta: *"Do Automation Rules support historical replay/backtesting of customer-defined payment policies, policy version comparison, or optimisation against a customer-specific risk appetite?"* Paste the answer word for word into `docs/spikes/SPIKE_E_OVERLAP.md`.
3. Skim `SPEC.md` §9, §17 and §21 on GitHub. The review doesn't block the agent, but check that nothing drifted.
4. Make the repo public, record the demo video and submit.

## Notes

- If a needed command keeps getting denied in headless mode, add it to `allow` in `.claude/settings.json`.
- Don't run with `--dangerously-skip-permissions` on a machine that has a wallet key in `.env`.
